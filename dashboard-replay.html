LINK (live)AP

Straight from the AP's counters, sampled every 200 ms and held for 30 s. Each station is drawn twice: the raw 200 ms samples faint, and a 3 s rolling mean solid over them. Three extra seconds of history are held off-screen so the mean is fully formed at the left edge rather than leaping about while its window fills. The mean is the trend; the faint trace is the transient you would otherwise average away. Both axes autoscale, with a floor on the span so a flat fleet is not magnified into noise. Read the gridline numbers, not just the shape. Uplink is a 2 s sliding average: a station sends one ~65 ms burst per wake interval, so a shorter window would sample burst-or-silence. tx failures are a running total, not a rate, so they are printed rather than plotted: a bar of a counter only ever shows which station has been up longest.

SERVICE PERIODS (live scope)AIR

Each tick is one PPDU the sniffer heard, at the time it was sent. Dashed bands are the commanded service periods, repeating every interval. More than one cycle because a single cycle cannot show that the pattern repeats: a reader cannot tell a schedule from a coincidence without seeing it happen more than once.

SESSION TOTALSAPAIR

Counters since this dashboard started, held by the server so a browser reload does not reset them. Compliance is counted per CAPTURE, not per station: a capture either had every measurable station inside its window or it did not. A station that produced too few frames to measure is absent from that capture, not failing; counting silence as compliance is how a dead station reads as healthy.

HEALTH: checking…

Runs every 5 minutes and repairs what is safely repairable: restarts the AP's iperf server if it has died, and puts the schedule back if it has drifted. It never touches a station. Exists because the fleet once sat in a degraded state for hours with nothing to notice.

SWITCH TWT CONFIGURATION

Applied from the AP over the air, with no station-side involvement and no re-association. Watch the scope rows move. Refused while a sweep is running, because two processes reconfiguring the same stations corrupts both datasets.
